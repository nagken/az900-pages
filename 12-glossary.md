# AZ-900 Glossary

| Term | Definition |
| --- | --- |
| **Region** | Set of datacenters in a geography (e.g., East US, West Europe). |
| **Region pair** | Two regions in the same geography linked for GRS replication + sequential update. |
| **Availability Zone** | Physically separate datacenter within an AZ-enabled region. |
| **Resource Group** | Logical container for resources sharing lifecycle. |
| **Subscription** | Billing + access boundary. |
| **Management Group** | Hierarchical container for subscriptions for unified policy + RBAC. |
| **IaaS** | Infrastructure as a Service - rent VMs/disks/networks. |
| **PaaS** | Platform as a Service - managed runtimes/databases. |
| **SaaS** | Software as a Service - full apps (M365, D365, Power BI). |
| **LRS** | Locally Redundant Storage - 3 copies, 1 datacenter. |
| **ZRS** | Zone Redundant Storage - 3 zones in 1 region. |
| **GRS** | Geo Redundant Storage - replicated to paired region (async). |
| **RA-GRS** | Read-Access GRS - read endpoint in paired region anytime. |
| **VPN Gateway** | Encrypted site-to-site or point-to-site over internet. |
| **ExpressRoute** | Private dedicated connection from on-prem to Azure. |
| **Conditional Access** | Entra policy enforcing access decisions based on signals. |
| **MFA** | Multi-factor authentication - something you know + something you have. |
| **RBAC** | Role-Based Access Control on Azure resources. |
| **Azure Policy** | Rules enforcing resource configuration. |
| **Resource Lock** | Prevents delete or change of a resource. |
| **CapEx** | Capital expense - upfront purchase. |
| **OpEx** | Operational expense - ongoing subscription. |
| **Tags** | Key/value metadata on resources for grouping and billing. |
| **SLA** | Service Level Agreement - uptime / performance guarantee. |
| **Bicep** | Modern Azure IaC DSL (preferred over ARM JSON). |
| **Azure Arc** | Extend Azure mgmt to on-prem/multicloud. |
