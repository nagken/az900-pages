# Microsoft Learn summaries (AZ-900)

One-line distillations of each Learn module.

- **Describe cloud computing**: Shared responsibility, cloud models (public/private/hybrid/multi), service models (IaaS/PaaS/SaaS), consumption pricing.
- **Benefits of cloud**: HA, scalability, elasticity, reliability, predictability, security, governance, manageability.
- **Service types**: IaaS = OS-level. PaaS = managed runtime. SaaS = full app.
- **Core architectural components**: Regions, region pairs, AZs, datacenters, resource hierarchy.
- **Compute + networking**: VM, VMSS, App Service, ACI, AKS, Functions; VNet, peering, VPN, ExpressRoute, DNS.
- **Storage services**: Blob/Disk/File/Queue/Table; LRS/ZRS/GRS/RA-GRS; Hot/Cool/Cold/Archive; AzCopy, Storage Explorer, Migrate, Data Box.
- **Identity + security**: Entra ID, Domain Services, SSO, MFA, Conditional Access, RBAC, Zero Trust, Defender for Cloud.
- **Cost management**: Pricing Calc, TCO Calc, Cost Management+Billing, factors, tags.
- **Governance + compliance**: Purview, Policy, Locks, Service Trust Portal.
- **Manage + deploy**: Portal, Cloud Shell, CLI, PowerShell, ARM/Bicep, Arc.
- **Monitoring**: Advisor, Service Health, Azure Monitor, App Insights.
